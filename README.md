# 📦 Redux Async API Fetch – JSONPlaceholder Example

This project demonstrates how to use **Redux** with **redux-thunk** middleware to handle asynchronous API calls using **Axios** in a JavaScript application.

It fetches TODO data from the public [JSONPlaceholder API](https://jsonplaceholder.typicode.com/) and stores it in Redux state.

---

## 🚀 Features

- ✅ Redux setup with actions, reducer, and store
- 🧵 Async middleware using `redux-thunk`
- 🌐 Axios-based API call to fetch todos
- 📦 Handles loading, success, and error states

---

## 🛠️ Tech Stack

- JavaScript
- Redux
- Redux Thunk
- Axios
- JSONPlaceholder API

---

## 🔍 API Used

- `GET https://jsonplaceholder.typicode.com/todos`
